服务商

Claude Code

  • 事件 hooks
  • 收到过 Claude Code 事件
  • 订阅额度

接入会在 里加上 hooks（原文件备份为 settings.json.dafeiyu.bak），新开的 Claude Code 会话生效。额度通过 claude /usage 查询，不消耗 token。

DeepSeek（DSH）

  • DSH 插件连接过桌宠
  • 最近收到 DSH 消息

在 DSH 中安装本插件即可接入（先卸载原版 dsh-dafeiyu）：

  1. 从 Release 页下载 agent-dafeiyu.tgz
  2. DSH →「插件 → 添加插件」，填入下载的 .tgz 的完整路径
  3. 插件设置里的「运行方式」保持「共享桌宠」

形象

内置皮肤可以直接点击切换；也可以到 petdex.dev 挑一只宠物，把它的名字或网页链接粘贴到上面再点「安装」。用 npx codex-pets add 装的宠物点「刷新」即可出现。也可以在桌宠右键「形象」里切换。

气泡文案

每行一句，随机挑一句显示；「干活中」里可以用 {task} 代表当前任务。留空的分组用内置文案。
