# 动作触发与衔接（0.2.3）

从 0.2.3 起，动作由守护进程里的 pet director 统一决定：它读取 Agent 状态、完成／出错脉冲、
鼠标互动和桌宠程序回报的“一段播完”，再告诉桌宠程序播哪一段。macOS、Windows / Linux Qt
和 Python 回退版共用同一套规则（`src/pet-director.js`、`src/animation-model.js`），
桌宠程序只负责播放、窗口与鼠标。共享桌宠模式由守护进程决定；独立桌宠模式由 DSH 插件按同一套模型决定。

动作清单来自 `assets/pet-manifest.json`：当前共 108 段、14,726 帧，统一画布 412 × 344
（最宽片段 612，窗口会为宽道具留出空间）。状态、互动和拖拽片段按源视频原生的 24 fps 播放
（每帧 42 毫秒）；装饰片段按 12 fps 编码（每帧 83 毫秒），体积约减半。

## 动作清单

| 动作 | 触发与频率 | 播放和衔接 |
| --- | --- | --- |
| 待机呼吸 | 空闲，或与 Agent 断开连接时 | 241 帧 × 42 毫秒 = 10.122 秒循环；断开时由气泡说明连接问题 |
| 思考冒泡 / 深度思考 / 敲桌子 | 回合开始、工具结束后继续整理 | 每段约 10 秒循环；同一状态里每播完一轮换一段，重复同类事件不会重播起点 |
| 忙碌点按 / 写代码 / 查找 / 清点归档 / 轻快记录 | 工具调用，按活动类型选择：`using-tool`、`editing`、`searching`、`commanding`、`testing` | 每段约 10 秒循环；同一状态内轮换同类动作（含敲桌子、东张西望等装饰片段） |
| 等待批准或回答 | 等待用户输入时 | 每段约 10 秒循环；在等待类动作之间轮换，直到等待解除 |
| 雀跃庆祝 | 一轮任务完成 | 完整播放 10.122 秒后回到最新状态；新的工作状态可立即打断 |
| 叹气冒汗 | 工具临时失败或回合出错 | 4.956 秒播一次；持续出错时保持末帧，直到状态改变 |
| 悬空拖拽 | 拖动角色 | 只循环源视频 2～8 秒的悬空段（144 帧 = 6.048 秒循环），拖到一半不会自行落地 |
| 松手落地 | 拖拽结束且不在屏幕边缘 | 接源视频 8 秒至结束的 49 帧，完整播 2.058 秒，再回最新任务状态；重新拖拽立即接管 |
| 贴边停靠 | 在屏幕左右边缘 16 像素内松手 | 侧转 90°，只露出约六成身体（头部）；停靠期间动作暂停、气泡隐藏；点一下或再次拖动就会出来，第一次点击只说一句“我出来啦~”，不触发摸头／戳 |
| 摸头 / 戳一戳 / 摸尾巴 | 点击角色的头、身体、尾巴；双击相当于摸头 | 互动片段完整播一次；同一部位轮换变体（摸头会在挠痒与害羞间切换，戳一戳会在挥手、开心、吓一跳间切换）；3 秒内连点 3 次会生气；普通互动之间至少间隔 1.2 秒，生气反应可以直接打断 |
| 伸懒腰 / 打哈欠 / 吃 Token 等 | 仅空闲时随机选择，不连续重复同一段 | 41 段待机小动作中随机；每段完整播放后再休息：安静 20～40 秒、标准 8～15 秒、活泼 3～6 秒 |
| 碎碎念 | 碎碎念档位开启且角色空闲 | 从 `say_*`、`deep_think` 和场景相关片段（吃饭、节日、余额等）里挑一段播一次（约 5～10 秒），同时显示气泡文案；忙碌时不播碎碎念动作，额度等紧急提醒只更新文案 |
| 拖动倾斜 | 拖动时按水平速度 | 朝移动方向倾斜，最多 14°；停下 90 毫秒后回正；“减少动态”下不倾斜 |
| 手动动作 | 右键「动作」菜单 | 从互动、日常、工作、才艺、玩耍、吃东西、节日、钱包分组里选一段完整播放，并说一句对应台词 |

## 优先级与绘制

- 状态循环、完成／出错脉冲、点击动作、待机小动作和拖拽分层处理，任何一层结束后都回到最新的 Agent 状态，不会无条件回到待机。
- 工作、等待和错误消息立即打断待机与点击动作；完成提示接管装饰动作，播放期间不接受新的点击动作。
- 拖拽和落地优先于点击动作；停靠时动作暂停，Agent 状态继续更新，取消停靠后显示最新状态。
- 待机小动作只在空闲、没有其他动作或提示时触发；点击动作有 1.2 秒冷却，连点会切到生气反应。
- 同一片段的连续帧直接绘制；不同片段之间使用 100 毫秒淡化；拖拽相关切换直接绘制，不叠加呼吸缩放、摇摆或逐帧淡变。
- 完成和错误提示不会抖动整个窗口。气泡、余额和任务列表变化保留角色坐标；Qt 在屏幕顶部空间不足时将气泡放到角色下方。停靠时气泡隐藏。
- “减少动态”固定角色姿势：不推进循环帧，不播放点击、待机小动作和碎碎念动画，拖动也不再倾斜；完成／出错提示直接显示结果末帧，状态文字、气泡和余额继续实时更新。
- 拖到屏幕物理左右边缘 16 像素内松手才会停靠；多屏拼接处不算屏幕外边缘。Dock／任务栏占用时也以物理边缘为准，取消停靠后回到可用工作区内。

## 素材核对与复现

本文件此前记录的 0.1.x 清单（16 段、3,444 帧，且称不播放随机待机与点击）已经过期。
当前清单为 108 段、14,726 帧，核心片段时长如下：

| 片段 | 帧数 | 时长 |
| --- | --- | --- |
| `idle`、`thinking`、`working`、`waiting`、`success` 等主循环 | 241 帧 | 10.122 秒 |
| `dragging`（悬空段） | 144 帧 | 6.048 秒 |
| `dragging_release`（落地段） | 49 帧 | 2.058 秒 |
| `error` | 118 帧 | 4.956 秒 |
| 装饰片段（12 fps） | 120 帧 | 约 9.96 秒 |

素材来自 [dsh-pet 固定版本](https://github.com/PC2005-cloud/dsh-pet/tree/eabaf20d4e19e8ac5ac2230d9de0f854a81a7f7b/dsh-pet/assets/webm)。
`assets/pet-manifest.json` 记录每个源视频的 SHA-256、帧范围和共同裁切窗口（x 100、宽 412、
高 344，24 fps，WebP q68），并记录状态映射、动作轮换和待机间隔；上游 MIT 许可证随包分发
（`assets/dsh-pet-LICENSE.txt`）。

```powershell
python scripts/import_dshpet_webm.py --source <该版本的dsh-pet/assets/webm> --ffmpeg <ffmpeg目录> --out .
npm test
npm run test:python
```

动画时长按运行时 42 毫秒／帧计算（装饰片段为 83 毫秒／帧）。源视频由 AI 生成，不同视频的
细节和角色比例仍有少量变化；修复播放规则不会重绘这些源图。
